🔒 Concurrency: Pessimistic Write Lock on seat fetch via @Lock(PESSIMISTIC_WRITE) — prevents double booking at DB level. Entire booking wrapped in @Transactional. Redis used for seat caching with Cache-Aside pattern.
💡 Discount (Strategy Pattern): ThirdTicketDiscountStrategy (50% off 3rd ticket) + AfternoonDiscountStrategy (20% off 12pm–5pm). New discounts added without modifying existing code — Open/Closed Principle.
